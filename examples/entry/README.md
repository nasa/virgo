# Entry Example

This directory provides an example of VIRGO rendering an atmospheric entry trajectory which demonstrates how a spacecraft sized object can approach very close to a planetary body. There are two examples self-contained within `entry.py` and `entry_extended.py` which both generates the data VIRGO reads and renders the scene using that data.  Important files in this directory:

* `entry.py`: Generates an "entry-like" trajectory then starts the scene
* `entry_extended.py`: Similar to `entry.py` but provides an example of extending VIRGO classes in order to customize behavior. This extension renders labels at atmospheric boundaries as the spacecraft crosses them.
* `log_trajectory.csv`: Untracked Trickpy-compliant data files generated by `entry*.py`
* `scene.yml`: YAML scene file representing the `dict` VIRGO needs to build the 3D scene

Please take a look at these files as there's extensive comments explaining the configuration.
