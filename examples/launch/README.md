## Launch Vehicle Example

This scene visualizes a simple launch vehicle ascending from KSC and provides an example of using the high resolution WGS-84 earth and KSC patch VIRGO_PREFAB actor for higher resolution at the ground.  The rocket is built from several primitive cylinders, the capsule mesh from `examples/splashdown/`, and a cone. The trajectory is a simplified launch provided by a script written by AI and is expressed in a frame relative to the launch pad. Note that orientation of the vehicle is not recorded to the `log_lv.csv` file yet so no pitch-over is visible in the scene.

* `launch.py`: Script that simulates a launch then launches VIRGO using `scene.yml` and `log_lv.csv`
* `log_lv.csv`: Tracked Trickpy-compliant data file generated by `launch.py`
* `scene.yml`: YAML scene file representing the `dict` VIRGO needs to build the 3D scene

Although not yet a robust complete example, this provides a useful test case for the KSC image/patch and WGS-84 high resolution earth which are defined in `scene.yml`.
